# F1 Championship Predictor — prototype gratuit

Ce dossier contient une première maquette fonctionnelle en HTML, CSS et JavaScript.

## Lancer le site sur ton ordinateur
1. Décompresse le fichier ZIP.
2. Ouvre le dossier `f1_championship_predictor`.
3. Double-clique sur `index.html` : le site s'ouvre dans ton navigateur.

Aucune installation ni aucun abonnement ne sont nécessaires pour tester cette maquette.

## Publier gratuitement avec GitHub Pages
1. Avec l'aide d'un parent si nécessaire, crée un compte GitHub.
2. Crée un dépôt public nommé `f1-championship-predictor`.
3. Envoie les quatre fichiers de ce dossier à la racine du dépôt.
4. Dans le dépôt, ouvre **Settings → Pages**.
5. Dans **Build and deployment**, choisis **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
6. GitHub affichera l'adresse publique du site après le déploiement.

## Important
- Les points, victoires et probabilités sont des données fictives de démonstration.
- Le simulateur utilise un barème simplifié de Grand Prix et ne modélise pas encore tous les concurrents.
- Aucune API officielle n'est connectée.
- Le projet est indépendant et n'est pas affilié à Formula 1 ou à la FIA.

## Prochaine étape
Connecter une source de données autorisée, créer une vraie base de données et développer un moteur de simulation qui tient compte de toutes les courses restantes, des sprints et des règles de départage.
